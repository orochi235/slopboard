transom

Capture everything your agents render in one place. Use it like an inbox or gallery on a second screen. Supports embedded pages, 3d meshes, and additional formats via plugins. Lets agents flag artifacts for your perusal and even solicit inline feedback. 

brew install orochi235/tap/transom
transom install    # daemon and client, as LaunchAgents
transom wire       # the skill and hook for Claude Code

The demo runs on a fixed set of real renders and a fake daemon, so nothing arrives from anywhere. Pictures still age out and the controls still work.

Why

Anyone who's done any amount of agentic coding on something visual (or had to provide tech support for family members over the phone) knows the frustration of having a halfhearted description read to you of something you can't see. After typing "JUST SHOW ME THE FUCKING RENDER" into Claude for the dozenth time while it was reasoning through some geometry decision that was literally incomprehensible without a diagram, it occurred to me that I could just have it open all of its output in Preview. Which is fine as long as you're OK with random windows popping up unannounced over your work and stealing focus all the time.

Eventually I got hoarse from yelling and built this. It's been indispensable to me ever since.

Posting to it

Writing the file is the whole protocol. There is nothing to start or connect to.

transom post render.png

The zone is the directory name of the repository you ran in, so a project is on the wall the first time it renders and nothing has to be bound. Wiring it to your own agents is one command. A zone is one pile, which is what makes “which projects are producing” answerable from across the room. Pipe a generator straight in, or pass --ttl, a caption, or a question the card (and agent) will wait for you to respond to.

How it is put together

A Node daemon watches ~/transom/inbox/, downscales what lands, and pushes it over a WebSocket. The client is React and three.js: one diagonal pile per zone, drawn in WebGL, read head-on at wall distance and zoomed into for the detail.

Layout from windease, menu bar widget by perch.
